Proceso de Reservación

ACID

Garantiza que una reservación, actualización de asientos y registro de pago se completen correctamente o se cancelen en conjunto.

BEGIN TRANSACTION; INSERT INTO Reservaciones (...); UPDATE Vuelos SET asientos_disponibles = asientos_disponibles - 1; INSERT INTO Pagos (...); COMMIT; -- ROLLBACK si ocurre error
Garantiza: No se puede reservar un asiento sin generar el pago correspondiente.

Check-In de Pasajeros

ACID

Verifica simultáneamente la disponibilidad del vuelo, la validez del pasaporte y actualiza el estado de la reservación.

BEGIN TRANSACTION; VALIDAR PASAPORTE; VERIFICAR ESPACIO DISPONIBLE; ACTUALIZAR RESERVACION SET estado = 'Check-In'; GENERAR PASE DE ABORDAR; COMMIT; -- ROLLBACK si alguna validación falla
Garantiza: El pasajero sólo podrá abordar si todas las validaciones fueron exitosas.
